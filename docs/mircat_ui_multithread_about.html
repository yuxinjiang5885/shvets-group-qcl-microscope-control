MIRcat Control Panel (Multi-threaded)

Python 3.9.6 64-bit and PyQT5

By Giovanni Sartorello (srtgnn@gmail.com)

Shortcuts

Ctrl + Q — quit the application.

Ctrl + U — switch from wavelengths in micrometers to wavenumbers in cm-1 and vice-versa.

Ctrl + M — open multiple acquisitions window.

Usage Notes

By default, using "repeat" does not plot data. Change this behavior in the "options" menu.

Experiment notes written in the text box will be saved to file in each experiment folder.

Known Issues

Shutting the laser down from this interface is unsupported. Please use the MIRcatControl utility or the power button on the laser.
